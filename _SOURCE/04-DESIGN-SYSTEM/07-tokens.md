# الرموز التصميمية — Design Tokens

`Design System` · v1.0
**المصدر الوحيد للحقيقة البصرية.** أي قيمة بصرية في أي مكوّن لا تأتي من هنا = عيب.

---

## 1. القاعدة

> **لا لون خام. لا مقاس خام. لا ظل خام. في أي مكوّن. أبدًا.**

| ❌ ممنوع | ✅ مطلوب |
|---|---|
| `color: '#C9A227'` | `text-accent-600` |
| `style={{ background: '#2E7D5B' }}` | `bg-ok-500` |
| `boxShadow: '0 4px 16px rgba(...)'` | `shadow-e2` |
| `borderRadius: '6px'` | `rounded-card` |
| `fontSize: '11px'` | `text-caption` |

**التنفيذ:** كل الرموز معرّفة في كتلة `@theme` في [`src/styles.css`](../../src/styles.css)، فيولّد Tailwind 4 أدوات المرافق منها تلقائيًا.

## 3. رموز الطباعة

```css
@theme {
  --font-sans: 'Cairo', 'Noto Sans Arabic', 'Segoe UI', system-ui, sans-serif;
  --font-mono: 'IBM Plex Mono', ui-monospace, 'SF Mono', Menlo, monospace;

  --text-display:  2.5rem;   /* 40px — قرار البوابة */
  --text-h1:       1.5rem;   /* 24px */
  --text-h2:       1.25rem;  /* 20px */
  --text-h3:       1.0625rem;/* 17px */
  --text-body:     0.9375rem;/* 15px — النص الأساسي */
  --text-sm:       0.875rem; /* 14px */
  --text-caption:  0.8125rem;/* 13px — ★ الحد الأدنى للنص الثانوي */
  --text-micro:    0.75rem;  /* 12px — الشارات فقط، لا نص متصل */
}
```

> **`DEF-031`:** الكود الحالي يستخدم `text-[10px]` و`text-[11px]` في **68 موضعًا**، غالبها بلون `mute` الراسب — مركّب من مشكلتين: نص صغير جدًا بتباين غير كافٍ. **الحد الأدنى الجديد 13px للنص المقروء، و12px للشارات المصحوبة بأيقونة.**

### مقياس الوزن والارتفاع

| الرمز | الوزن | الارتفاع | الاستخدام |
|---|---|---|---|
| `display` | 800 | 1.15 | قرار البوابة |
| `h1` | 700 | 1.3 | عنوان الصفحة |
| `h2` | 700 | 1.35 | عنوان القسم |
| `h3` | 600 | 1.4 | عنوان البطاقة |
| `body` | 400 | **1.75** | النص العربي المتصل |
| `body-strong` | 600 | 1.75 | تأكيد |
| `caption` | 400 | 1.6 | ثانوي |
| `label` | 600 | 1.4 | تسمية حقل |
| `numeric` | 600 | 1.2 | أرقام · `tabular-nums` |

**قاعدة الخط العربي:** Cairo يرسم مضغوطًا. النص العربي المتصل يحتاج **1.75** لا 1.5 كاللاتيني.

## 5. رموز الاستدارة والحدود

```css
@theme {
  --radius-ctl:  6px;   /* أزرار · مدخلات · شارات */
  --radius-card: 10px;  /* البطاقات — كان 6px */
  --radius-panel:14px;  /* اللوحات الكبيرة · الحوارات */
  --radius-pill: 999px; /* الشارات الدائرية */
}
```

> **التغيير:** استدارة البطاقة رُفعت من 6px إلى **10px**. عند 6px تقرأ البطاقة «مربعة تقنية»؛ عند 10px تقرأ «منتج حديث» دون أن تفقد الجدية. الأزرار تبقى 6px — الفرق بين الحاوية والتحكم مقصود ويخلق تسلسلًا.

## 6. رموز الارتفاع (الظلال)

خمس درجات، كلها **مائلة لأزرق العلامة** لا رمادية — الظل الرمادي على سطح مائل للأزرق يقرأ متسخًا:

```css
@theme {
  --shadow-e0: none;
  --shadow-e1: 0 1px 2px rgb(14 42 71 / 0.06),
               0 1px 3px rgb(14 42 71 / 0.04);   /* بطاقة ساكنة */
  --shadow-e2: 0 2px 4px rgb(14 42 71 / 0.06),
               0 6px 16px rgb(14 42 71 / 0.08);  /* بطاقة مرفوعة */
  --shadow-e3: 0 4px 8px rgb(14 42 71 / 0.08),
               0 12px 28px rgb(14 42 71 / 0.12); /* قائمة منسدلة · تلميح */
  --shadow-e4: 0 8px 16px rgb(14 42 71 / 0.10),
               0 24px 56px rgb(14 42 71 / 0.16); /* حوار */
  --shadow-focus: 0 0 0 2px var(--color-n-000),
                  0 0 0 4px var(--color-brand-700);
}
```

**على الأسطح الداكنة لا ظل** — الارتفاع يُعبَّر عنه بتفتيح السطح (`brand-700` → `brand-600`) وحد `1px` بلون `rgb(255 255 255 / 0.06)`.

## 10. التحقق من الالتزام

```bash
# لا ألوان خام سداسية خارج styles.css
grep -rn "#[0-9A-Fa-f]\{6\}" src/ --include=*.tsx | grep -v "styles.css"

# لا مقاسات نص خارج المقياس
grep -rn "text-\[1[01]px\]" src/

# لا ظلال مضمّنة
grep -rn "boxShadow" src/ --include=*.tsx
```

**الحصيلة المستهدفة: صفر في الثلاثة.**

| الفحص | قبل | بعد |
|---|---|---|
| ألوان خام في `.tsx` | 34 | **0** |
| `text-[10px]` / `text-[11px]` | 68 | **0** |
| ظلال مضمّنة | 9 | **0** |
