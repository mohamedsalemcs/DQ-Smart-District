`Design System` · v1.0

# الجزء الأول · الحركة

## 1. المبدأ

> **الحركة تشرح تغيّرًا. إن لم تشرح شيئًا فهي تأخير.**

في منتج تشغيلي يستخدمه حارس على بوابة، كل ميلي ثانية حركة هي ميلي ثانية تأخير في القرار. لذلك:

| السياق | ميزانية الحركة |
|---|---|
| شاشة البوابة | **80ms كحد أقصى** — ولا حركة على لوحة القرار إطلاقًا |
| تطبيق الأمن | 140ms |
| تطبيق الإدارة | 200ms |
| تطبيق المقيم | 200–320ms |

## 2. المنحنيات والمدد

```css
--ease-out:    cubic-bezier(0.16, 1, 0.3, 1);    /* الدخول — سريع ثم يستقر */
--ease-in-out: cubic-bezier(0.65, 0, 0.35, 1);   /* التحوّل بين حالتين */

--dur-instant: 80ms;   /* تغذية راجعة للضغط */
--dur-fast:   140ms;   /* تحويم · تركيز · تبديل شارة */
--dur-base:   200ms;   /* ظهور عنصر · فتح قائمة */
--dur-slow:   320ms;   /* حوار · درج */
```

**لا `ease-in` منفردًا أبدًا** — يجعل العنصر يبدو بطيء الاستجابة عند بدايته.

## 3. جدول الحركات

| الحركة | المدة | المنحنى | التحوّل |
|---|---|---|---|
| تحويم زر | 140ms | `ease-out` | `background` · `border` |
| ضغط زر | 80ms | `ease-out` | `scale(0.98)` |
| ظهور حلقة تركيز | فوري | — | **بلا حركة** — التركيز يجب أن يكون فوريًا |
| ظهور بطاقة | 200ms | `ease-out` | `opacity` + `translateY(6px)` |
| فتح حوار | 320ms | `ease-out` | `opacity` + `scale(0.97→1)` |
| فتح درج | 320ms | `ease-out` | `translateX(100%→0)` منطقيًا |
| توست | 200ms | `ease-out` | `opacity` + `translateY(10px)` + `scale(0.98)` |
| نبض بلاغ نشط | 1600ms حلقي | `ease-in-out` | `opacity 1→0.3` |
| حلقة نبض (مركبة موقوفة) | 2000ms حلقي | `ease-out` | `box-shadow` متمدد |
| عدّاد الاستجابة | 1000ms | خطي | تحديث نصي — **بلا حركة على الرقم** |

## 4. ما لا يتحرك أبدًا

| العنصر | لماذا |
|---|---|
| **لوحة قرار البوابة** | تظهر فورًا. أي حركة تؤخر القرار الحرج |
| **الأرقام في المؤشرات** | العدّ التصاعدي يجعل القيمة غير مقروءة أثناءه |
| **حلقة التركيز** | التنقل بلوحة المفاتيح يجب أن يكون فوريًا |
| **محتوى الجدول عند الفرز** | إعادة ترتيب متحركة تربك التتبّع |
| **موضع الدوريات على الخريطة** | تتحرك بالبيانات لا بحركة CSS |

## 5. تقليل الحركة — إلزامي

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    transition-duration: 0.01ms !important;
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    scroll-behavior: auto !important;
  }
}
```

**تنبيه:** الكود الحالي يلغي `transition-duration` فقط ولا يلغي `animation-duration` ولا `animation-iteration-count` — فتبقى `pulse-dot` تنبض بلا نهاية لمن طلب تقليل الحركة (`DEF-054`). النبض المستمر محفّز معروف لحساسية الحركة الدهليزية.

# الجزء الثاني · تصوير البيانات

## 6. اختيار الشكل

| السؤال | الشكل | مثال |
|---|---|---|
| كيف يتغيّر بمرور الوقت؟ | خط أو منطقة | حركة البوابات · زمن الاستجابة |
| كم لكل فئة؟ | أعمدة أفقية | قرارات كل بوابة · أنواع البلاغات |
| ما التركيب؟ | دائري مجوّف (**≤5 شرائح**) | حالات الطلبات |
| ما القيمة الآن مقارنة بما قبل؟ | مؤشر + دلتا + خط مصغّر | كل بطاقات اللوحة |
| أين يحدث؟ | خريطة | مواقع البلاغات · الخريطة الحرارية |

**قاعدة الدائري:** أكثر من خمس شرائح ⇒ أعمدة. الدائري يكذب عند التقارب.
**قاعدة العمود الأفقي:** التسميات العربية طويلة — العمود الأفقي يستوعبها، والرأسي يقصّها أو يميلها.

## 7. لوحة الألوان

| الرمز | القيمة | الدور |
|---|---|---|
| `viz-1` | `#2E5480` | السلسلة الأساسية |
| `viz-2` | `#C8A02E` | السلسلة الثانية |
| `viz-3` | `#1E7A4E` | إيجابي — المغلق · المنجز |
| `viz-4` | `#A32C1F` | سلبي — المرفوض · المخالفات |
| `viz-5` | `#7BA0C8` | **المقارنة بالفترة السابقة — دائمًا متقطع** |
| `viz-6` | `#9C6410` | تحذيري — المتأخر |

### قواعد

1. **سلسلة واحدة ⇒ `viz-1` وحده.** لا تلوين متعدد بلا معنى.
2. **المقارنة بالفترة السابقة ⇒ `viz-5` + خط متقطع.** لا تُميَّز باللون وحده (`BR-007`).
3. **الخريطة الحرارية ⇒ تدرج أحادي** من `brand-050` إلى `brand-700`. **لا قوس قزح أبدًا** — غير متسق إدراكيًا ويفشل مع عمى الألوان.
4. **لا تُشتق ألوان الرسوم من ألوان الحالة.** الرسم يجيب «كم»، والحالة تجيب «ما هي». خلطهما يجعل عمودًا بلون خطر يبدو إنذارًا وهو مجرد فئة.

### التحقق من عمى الألوان

اللوحة مختبَرة تحت محاكاة deuteranopia و protanopia و tritanopia. الزوج الحرج `viz-3` (أخضر) و`viz-4` (أحمر) يظل متمايزًا بفارق سطوع **1.9:1** — ومع ذلك **لا يُستخدمان متجاورين بلا وسم نصي**.

## 8. قواعد المحاور والشبكة

| العنصر | القاعدة |
|---|---|
| المحور السيني (الزمن) | **يمين ← يسار** في RTL — الأحدث في اتجاه بداية القراءة |
| المحور الصادي | يبدأ من **صفر** إلا مع تبرير مكتوب |
| خطوط الشبكة | `n-100` عرض 1px · **أفقية فقط** |
| التسميات | 12px `n-500` — أقل من هذا لا يُقرأ |
| الأرقام | `tabular-nums` دائمًا |
| نقاط البيانات | تُظهر عند التحويم فقط، إلا إن كانت ≤ 12 نقطة |

## 9. التلميحات

```
┌──────────────────────────┐
│ 14 يوليو 2026            │  ← 12px · n-500
│ ━━ مسموح          1,284  │  ← 13px · لون السلسلة + tabular
│ ┅┅ مرفوض             37  │
│ ─────────────────────────│
│ الفترة السابقة    1,102  │  ← 12px · viz-5
└──────────────────────────┘
```

خلفية `n-000` · ظل `e3` · استدارة `card` · حشوة 12px · **كل سلاسل نفس النقطة معًا** لا واحدة.

## 10. الحالات الفارغة والجزئية

| الحالة | المعالجة |
|---|---|
| لا بيانات | حالة فراغ مصمَّمة تشرح السبب — **لا رسم فارغ بمحاور** |
| بيانات جزئية | يُرسم الموجود + نص «بيانات 5 أيام من 7» |
| قيمة صفر | تُرسم صفرًا صريحًا — لا تُحذف النقطة |
| قيمة شاذة | تُرسم ويُوسم عندها |

## 11. الوصولية

| المتطلب | التنفيذ |
|---|---|
| بديل نصي | `<figcaption>` يلخّص ما يقوله الرسم |
| جدول مكافئ | زر «عرض كجدول» يفتح البيانات الخام |
| لا اعتماد على اللون | نمط الخط (صلب/متقطع/منقّط) + وسم مباشر |
| قابلية التركيز | الأسطورة قابلة للتركيز وتبديل السلاسل |
| التباين | كل الألوان ≥ 3:1 مع الخلفية |

**مثال `<figcaption>`:** «حركة البوابات خلال 30 يومًا: ارتفاع من 980 إلى 1,284 دخولًا يوميًا، بانخفاض ملحوظ كل جمعة وسبت. حالات الرفض بقيت تحت 40 يوميًا.»

هذا ليس ترفًا — هو ما يقرؤه من لا يرى الرسم، **وهو أيضًا ما يجب أن يستنتجه من يراه**. إن تعذّرت كتابته، فالرسم لا يقول شيئًا.
