# الطباعة — Typography

`Design System` · v1.0

---

## 1. العائلات

| الدور | العائلة | الأوزان | لماذا |
|---|---|---|---|
| **الواجهة والنص** | `Cairo` | 400 · 500 · 600 · 700 · 800 | خط عربي هندسي معاصر، بنية واضحة عند المقاسات الصغيرة، وله وزن 800 يحتمل شاشة البوابة |
| **الأرقام والرموز** | `IBM Plex Mono` | 500 · 600 | اللوحات وأرقام المعاملات وبصمات التحقق ورموز QR — تحتاج عرضًا ثابتًا لتُمسح بصريًا |
| **الاحتياط** | `Noto Sans Arabic` → `Segoe UI` → `system-ui` | | |

**لماذا لا خط عربي كلاسيكي (نسخ/ثلث):** المنتج تشغيلي يُقرأ في ثوانٍ، لا وثيقة رسمية تُتأمَّل. الخطوط الكلاسيكية ترتفع فيها الفروق بين المحارف عند 12–14px وتقل المقروئية. Cairo هندسي منخفض التباين الداخلي — أوضح مقاس صغير.

## 2. المقياس

مقياس أساسه 15px بنسبة ~1.2، مقصوص عند سبع درجات فقط:

| الرمز | المقاس | الوزن | ارتفاع السطر | الاستخدام |
|---|---|---|---|---|
| `display` | **40px** | 800 | 1.15 | قرار البوابة حصرًا |
| `h1` | **24px** | 700 | 1.30 | عنوان الصفحة |
| `h2` | **20px** | 700 | 1.35 | عنوان القسم |
| `h3` | **17px** | 600 | 1.40 | عنوان البطاقة |
| `body` | **15px** | 400 | **1.75** | النص المتصل |
| `caption` | **13px** | 400 | 1.60 | النص الثانوي — **الحد الأدنى المقروء** |
| `micro` | **12px** | 600 | 1.40 | الشارات المصحوبة بأيقونة فقط |

### قاعدة ارتفاع السطر العربي

> **النص العربي المتصل: 1.75. لا 1.5.**

Cairo يرسم مضغوطًا رأسيًا، والعربية فيها نقاط أسفل وأعلى الخط (ب، ج، ي، ظ) تصطدم عند 1.5. الفرق بين 1.5 و1.75 على فقرة من أربعة أسطر هو الفرق بين نص يُقرأ ونص يُتخطى.

| النوع | الارتفاع |
|---|---|
| نص متصل (`p`, `li`, `dd`) | **1.75** |
| عناوين | 1.30–1.40 |
| تسميات وشارات | 1.40 |
| أرقام مفردة | 1.20 |

## 3. الحد الأدنى — القاعدة الجديدة

> **13px هو الحد الأدنى لأي نص يُقرأ. 12px للشارات المصحوبة بأيقونة فقط. لا شيء تحت 12px إطلاقًا.**

### العيب `DEF-031`

| المقاس | عدد المواضع في الكود الحالي | التقييم |
|---|---|---|
| `text-[9px]` | 3 | ❌ غير مقروء |
| `text-[10px]` | 31 | ❌ تحت الحد |
| `text-[11px]` | 34 | ❌ تحت الحد |
| **الإجمالي** | **68** | |

والأسوأ أن أغلبها مقترن بلون `mute` (تباين 4.38 ❌) أو `steel` (3.46 ❌) — **مشكلتان مركّبتان**: نص صغير جدًا بتباين غير كافٍ. مثال حقيقي من [`Shell.tsx:95`](../../src/app/Shell.tsx#L95):

```tsx
<p className="text-[10px] leading-tight text-steel">{roleAr[user.role]}</p>
```
دور المستخدم — معلومة تعريفية — بمقاس 10px وتباين 3.46.

### خريطة الاستبدال

| كان | يصبح | القاعدة |
|---|---|---|
| `text-[9px]` | `text-micro` (12px) | ارفع أو احذف |
| `text-[10px]` | `text-micro` (12px) | شارة فقط؛ إن كان نصًا → `caption` |
| `text-[11px]` | `text-caption` (13px) | |
| `text-xs` (12px) نصًا متصلًا | `text-caption` (13px) | |
| `text-mute` | `text-n-500` | 4.38 → **5.30** |
| `text-steel` (على داكن) | `text-brand-200` | 3.46 → **9.18** |

## 4. الطباعة حسب السياق

### 4.1 شاشة البوابة — تُقرأ من 3 أمتار 🔴

| العنصر | المقاس | الوزن | لماذا |
|---|---|---|---|
| القرار («الدخول مرفوض») | **40px** | 800 | يُلمَح لا يُقرأ |
| السبب | **20px** | 500 | يُقرأ من متر |
| اللوحة | **28px** أحادي | 600 | العنصر الذي يُطابَق بالعين |
| تفاصيل الإيقاف | 15px | 400 | يُقرأ عن قرب |
| سجل البوابة | 13px | 400 | مرجع لا قرار |

**قاعدة المسافة:** المقاس المطلوب للقراءة من مسافة `م` بالمتر ≈ `م × 14px` كحد أدنى. من 3 أمتار ⇒ **42px**. اخترنا 40px لأن الوزن 800 والتباين AAA يعوّضان.

### 4.2 تطبيق المقيم — هاتف بيد واحدة

- النص الأساسي **15px** — لا 14px؛ الفرق ملموس على الهاتف
- التسميات **13px وزن 600** — التمييز بالوزن لا بالمقاس
- الأزرار **15px وزن 600**، ارتفاع لمس ≥ 44px

### 4.3 تطبيق الإدارة — كثافة عالية

- صفوف الجداول **14px** — أقصى كثافة مقبولة
- رؤوس الأعمدة **12px وزن 700 وتتبّع `0.04em`**
- أرقام المؤشرات **28px وزن 700 `tabular-nums`**
- كل الأرقام في الجداول `tabular-nums` — بدونها لا تصطف الأعمدة

## 5. الأرقام

### قاعدة إلزامية

```css
font-feature-settings: 'lnum' 1, 'tnum' 1;
```

- `lnum` — **أرقام غربية** (0123456789) لا هندية (٠١٢٣٤٥٦٧٨٩)
- `tnum` — **عرض ثابت**، لتصطف الأعمدة والأوقات

**لماذا الأرقام الغربية في واجهة عربية:** لوحات المركبات السعودية تُطبع بالأرقام الغربية، وأرقام المعاملات كذلك، والحارس يطابق ما على الشاشة بما على المركبة. اختلاف نظام الأرقام بين الشاشة والواقع يخلق خطأ مطابقة. القرار مُوثَّق في `ADR-005`.

### العزل الاتجاهي — `BR-006`

كل مقطع لاتيني داخل نص عربي **يُعزَل**:

```tsx
<span>اللوحة <bdi className="plate">ن د ب 4821</bdi> مرفوضة</span>
<bdi dir="ltr" className="plate">DQ-2026-000431</bdi>
```

بلا `<bdi>` تنقلب الأرقام وتظهر `1284` بدل `4821` — خطأ مطابقة كارثي عند البوابة.

**المطبَّق على:** لوحات المركبات · أرقام المعاملات · رموز QR · بصمات sha-256 · أرقام الجوال · أرقام الهوية · رموز الوحدات · الأوقات بصيغة `HH:mm`.

## 7. التسلسل بلا مقاس

المقاس ليس الأداة الوحيدة. بترتيب الأفضلية:

1. **الوزن** — 700 مقابل 400 عند نفس المقاس يخلق تسلسلًا بلا كلفة مساحية
2. **اللون** — `n-800` مقابل `n-500`
3. **المسافة** — الفراغ فوق العنوان يفصل أقوى من تكبيره
4. **المقاس** — آخر أداة، لأنها الأكثر كلفة

هذا يُبقي المقياس عند سبع درجات ويمنع تضخمه.

## 8. الجدول التنفيذي

```css
@theme {
  --text-display:  2.5rem;    /* 40px */
  --text-h1:       1.5rem;    /* 24px */
  --text-h2:       1.25rem;   /* 20px */
  --text-h3:       1.0625rem; /* 17px */
  --text-body:     0.9375rem; /* 15px */
  --text-caption:  0.8125rem; /* 13px */
  --text-micro:    0.75rem;   /* 12px */
}
```

| الفحص | قبل | الهدف |
|---|---|---|
| مقاسات تحت 12px | 68 | **0** |
| نص ثانوي راسب التباين | كل المواضع | **0** |
| مقاسات عشوائية `text-[Npx]` | 71 | **0** |
| ارتفاع سطر النص العربي | 1.7 | **1.75** |
