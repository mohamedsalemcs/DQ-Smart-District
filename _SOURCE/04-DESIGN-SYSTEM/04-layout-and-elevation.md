# التخطيط والارتفاع — Layout & Elevation

`Design System` · v1.0

---

## 1. الشبكة

### 1.1 الوحدة الأساس: 4px

كل مسافة ومقاس مضاعف لـ4. لا استثناء.

| الرمز | القيمة | الاستخدام |
|---|---|---|
| `space-1` | 4px | داخل الشارة · بين أيقونة صغيرة ونص |
| `space-2` | 8px | بين أيقونة ونص · بين شارتين |
| `space-3` | 12px | داخل عنصر قائمة مضغوط |
| `space-4` | **16px** | **حشوة البطاقة القياسية** |
| `space-5` | 20px | حشوة بطاقة واسعة |
| `space-6` | **24px** | **بين البطاقات** |
| `space-8` | 32px | بين الأقسام |
| `space-12` | 48px | بين المناطق الكبرى |

### 1.2 قواعد الإيقاع

| العلاقة | المسافة | القاعدة |
|---|---|---|
| تسمية ← حقلها | 4px | القرب يعني الانتماء |
| حقل ← الحقل التالي | 16px | |
| مجموعة حقول ← المجموعة التالية | 24px | |
| عنوان القسم ← محتواه | 16px | |
| قسم ← القسم التالي | 32px | |

> **المبدأ:** المسافة **فوق** العنصر تنتمي إليه، والمسافة **تحته** تفصله عمّا بعده. الفراغ داخل المجموعة أصغر دائمًا من الفراغ بينها وبين ما يجاورها — وهذا وحده يبني التسلسل بلا خطوط ولا صناديق.

## 2. RTL — التخطيط المنطقي

### القاعدة المطلقة

> **لا `left` ولا `right` ولا `ml-` ولا `pr-` في أي مكوّن. أبدًا.**

| ❌ فيزيائي | ✅ منطقي |
|---|---|
| `ml-2` | `ms-2` (margin-inline-start) |
| `pr-4` | `pe-4` (padding-inline-end) |
| `text-left` | `text-start` |
| `border-l` | `border-s` |
| `left-0` | `start-0` |
| `rounded-tl-lg` | `rounded-ss-lg` |

الجذر يحمل `dir="rtl"`، وكل الأدوات المنطقية تنعكس تلقائيًا. **الكود الحالي ملتزم بهذا بالكامل** — نقطة قوة حقيقية تستحق الحفاظ عليها.

### الاستثناءات الثلاثة المشروعة

| الحالة | المعالجة | لماذا |
|---|---|---|
| اللوحات وأرقام المعاملات | `<bdi>` + `dir="ltr"` | لا تنقلب أبدًا |
| نجوم التقييم | `dir="ltr"` صراحة | تُقرأ يسار←يمين عالميًا |
| الرسوم البيانية الزمنية | محور الزمن يمين←يسار | الأحدث في اتجاه بداية القراءة |

### سلّم التصعيد في RTL

```
الدرجة 5      4      3      2      1      0
  ○──────○──────○──────●──────✓──────✓
                       ↑ الحالية        ↑ البداية (أقصى اليمين)
```

الدرجة 0 **أقصى اليمين** والتقدّم نحو اليسار. عكس ذلك يقلب معنى التقدّم للقارئ العربي.

## 3. تخطيطات الصفحات

### 3.1 هيكل الغلاف

```
┌─────────────────────────────────────────────────────────┐
│  الشريط العلوي — 60px لاصق                      z:30   │
│  [شعار]        [سرعة] [الشخصية] [الجرس] [المستخدم]      │
├──────────┬──────────────────────────────────────────────┤
│ الشريط   │                                              │
│ الجانبي  │            منطقة المحتوى                     │
│ 232px    │            أقصى عرض 1440px                   │
│ لاصق     │            حشوة 24px                         │
│ z:20     │                                              │
└──────────┴──────────────────────────────────────────────┘
```

**التغيير:** الشريط الجانبي من 224px إلى **232px**، والشريط العلوي من 56px إلى **60px**. السبب: عند 56px والشعار 32px يتبقى 12px هامشًا علويًا وسفليًا — ضيق يجعل الشريط يبدو مكتظًا. و232px تستوعب أطول عنصر تنقل («تنظيم دخول السفارات») بلا قص.

### 3.2 أنماط المحتوى الأربعة

| النمط | التخطيط | يُستخدم في |
|---|---|---|
| **عمود القراءة** | 720px موسّط | النماذج · تفاصيل الطلب · المحضر · الإعدادات |
| **طابور/تفصيل** | `2fr · 3fr` بفجوة 24px | المخالفات · الطلبات · البلاغات |
| **لوحة** | شبكة متجاوبة `minmax(240px, 1fr)` | لوحة القيادة · التقارير · غرفة العمليات |
| **ملء الشاشة** | 100% بلا حشوة | التوأم الرقمي · لوحة قرار البوابة |

### 3.3 نقاط الانكسار

| الاسم | العرض | السلوك |
|---|---|---|
| `sm` | 640px | عمود واحد → عمودان في الشبكات |
| `md` | 768px | يظهر عمود التفاصيل |
| `lg` | **1024px** | **الشريط الجانبي يصبح لاصقًا؛ تحته درج** |
| `xl` | 1280px | ثلاثة أعمدة في اللوحات |
| `2xl` | 1536px | أقصى عرض 1440px |

**الأولوية:** الأمن لوحي (768–1024) · الإدارة مكتبي (≥1280) · المقيم هاتف (375–430).

## 4. الارتفاع

### 4.1 على الأسطح الفاتحة — الظل

خمس درجات، كلها **مائلة لأزرق العلامة** لا رمادية:

| الدرجة | القيمة | الاستخدام |
|---|---|---|
| `e0` | `none` | مسطّح · داخل بطاقة |
| `e1` | `0 1px 2px / 0.06, 0 1px 3px / 0.04` | البطاقة الساكنة |
| `e2` | `0 2px 4px / 0.06, 0 6px 16px / 0.08` | بطاقة مرفوعة · تحويم |
| `e3` | `0 4px 8px / 0.08, 0 12px 28px / 0.12` | قائمة منسدلة · تلميح · درج |
| `e4` | `0 8px 16px / 0.10, 0 24px 56px / 0.16` | حوار |

> **لماذا مائل للأزرق:** الظل الرمادي `rgba(0,0,0,α)` فوق سطح مائل للأزرق (`n-025`) يقرأ **متسخًا**. الظل بلون العلامة `rgb(14 42 71 / α)` يقرأ كطبقة هوائية.
> **لماذا طبقتان لكل ظل:** الطبقة الضيقة ترسم حدًا واضحًا، والواسعة توحي بالعمق. الطبقة الواحدة تبدو إما حادة أو ضبابية.

### 4.2 على الأسطح الداكنة — لا ظل

الظل غير مرئي على الداكن. الارتفاع يُعبَّر عنه بـ**تفتيح السطح**:

| المستوى | السطح | + الحد |
|---|---|---|
| الخلفية | `brand-800` `#0A1F35` | — |
| البطاقة | `brand-700` `#0E2A47` | `1px rgb(255 255 255 / 0.06)` |
| مرتفع | `brand-600` `#1B3E63` | `1px rgb(255 255 255 / 0.08)` |
| حوار | `brand-600` | `1px rgb(255 255 255 / 0.12)` + حاجب |

### 4.3 نموذج الطبقات

| الطبقة | z-index | العناصر |
|---|---|---|
| الأساس | 0 | المحتوى |
| اللاصق | 10 | رؤوس الجداول |
| التنقل | 20 | الشريط الجانبي |
| الرأس | 30 | الشريط العلوي |
| الحاجب | 40 | خلفية الحوار |
| الحوار | 50 | الحوارات · الأدراج |
| التوست | 60 | الإشعارات العائمة |
| التلميح | 70 | التلميحات |

**القاعدة:** لا `z-index` رقميًا في أي مكوّن — من الرموز فقط. المصدر الحالي فيه `z-[60]` مباشرة في `ToastHost` (`DEF-051`).

## 5. الاستدارة

| الرمز | القيمة | العناصر |
|---|---|---|
| `ctl` | **6px** | أزرار · مدخلات · شارات · عناصر تنقل |
| `card` | **10px** | البطاقات · اللوحات |
| `panel` | **14px** | الحوارات · الأدراج · لوحة قرار البوابة |
| `pill` | **999px** | الشارات الدائرية · مبدّلات |

> **التغيير:** البطاقة من 6px إلى **10px**، والحوار إلى **14px**.
> **السبب:** 6px يقرأ «مربع تقني»؛ 10px يقرأ «منتج حديث» بلا فقدان الجدية. والأهم أن الفرق بين الحاوية (10px) والتحكم داخلها (6px) **يبني تسلسلًا بصريًا مجانيًا** — العين تعرف ما يحتوي ما.
>
> **قاعدة التداخل:** استدارة العنصر الداخلي = استدارة الحاوية − الحشوة. زر 6px داخل بطاقة 10px بحشوة 16px متناسق. زر 10px داخل بطاقة 10px يبدو خاطئًا.

## 7. الكثافة حسب الشخصية

نفس الرموز، ثلاثة إيقاعات:

| البُعد | المقيم | الإدارة | الأمن |
|---|---|---|---|
| حشوة البطاقة | 20px | 16px | 16px |
| بين البطاقات | 24px | 16px | 16px |
| ارتفاع الصف | 56px | 44px | 48px |
| النص الأساسي | 15px | 15px | 15px |
| الأعمدة | 1 | 2–3 | 2 |
| عرض المحتوى | 720px | 1440px | 1200px |

**الفرق بين الشخصيات كثافة لا لون.** المقيم يتنفّس، والإدارة تكثّف، والأمن بينهما (لوحي + سرعة قراءة). هذا أصدق وأكثر فائدة من تلوين تعسفي لكل شخصية.
