# الهوية والشعار — Brand & Logo

`Design System` · v1.0

---

## 1. المشكلة الحالية

الشعار اليوم ليس شعارًا:

```tsx
<span className="flex h-8 w-8 items-center justify-center rounded-[6px] bg-gold font-bold text-navy">DQ</span>
```

مربع ذهبي بحرفين لاتينيين، في منتج **عربي بالكامل RTL** يخدم حيًا دبلوماسيًا سعوديًا. المشكلات:

1. **لاتيني في منتج عربي** — الحرفان `DQ` أول ما تراه العين في واجهة كل حرف آخر فيها عربي
2. **لا يقبل التصغير أو التكبير** — نص في مربع، لا شكل
3. **لا معنى** — لا يقول شيئًا عن الحي ولا عن البوابة ولا عن الأمان
4. **لا نسخ** — لا نسخة أفقية ولا أحادية اللون ولا للطباعة
5. **يفشل على الداكن والفاتح معًا** — نفس المربع الذهبي في السياقين

## 2. مفهوم الشعار

### الفكرة: **البوابة والدرع**

الحي الدبلوماسي محكوم بمفهومين: **حدّ** (البوابة التي تفصل) و**حماية** (ما بداخل الحد). الشعار يدمجهما في علامة واحدة:

```
        ╭───────────╮          القوس  = البوابة · المدخل · الاستقبال
       ╱             ╲         الدرع  = الحماية · الحدّ · الأمان
      │   ╱───────╲   │        الفتحة = حيّ مفتوح لا حصن مغلق
      │  │    ▲    │  │        المثلث = الشعاب · نجدية · صعود
      │  │   ╱ ╲   │  │
      │   ╲───────╱   │
       ╲             ╱
        ╰───▁▁▁▁▁───╯
```

**التركيب الهندسي:**
- **الحد الخارجي**: درع بقوس علوي ورأس سفلي — نصف قطر القوس = عرض الشكل ÷ 2 بالضبط
- **الفراغ الداخلي**: قوس مطابق مصغَّر بنسبة 0.68 — يخلق «عتبة» البوابة
- **العنصر المركزي**: مثلث صاعد — إشارة إلى تضاريس نجد وإلى الارتقاء
- **الفتحة السفلية**: انقطاع مقصود في قاعدة الدرع — الحي **مدخل** لا **سور**

**لماذا هذه الفكرة تحديدًا:** الادعاء المعماري للمنتج كله هو أن القرار الإداري يصبح إنفاذًا عند البوابة. البوابة ليست تفصيلة تشغيلية — هي **المفصل** الذي يثبت أن النظام يعمل. أن يكون الشعار بوابة يعني أن العلامة تقول ما يفعله المنتج.

### شبكة البناء

```
0        8       16       24       32
├────────┼────────┼────────┼────────┤  32×32 شبكة أساس
│                                   │
│    ╭───────────────────────╮      │  y=4   بداية القوس
│                                   │
│                                   │  y=13  مركز الشكل البصري
│                                   │
│         ╲             ╱           │  y=24  بداية التقارب
│           ╲         ╱             │
│             ╲     ╱               │  y=29  الرأس
└───────────────────────────────────┘

الهامش الآمن = 4 وحدات من كل جهة (12.5% من العرض)
لا يوضع أي عنصر داخل الهامش الآمن أبدًا
```

## 3. نسخ الشعار

| النسخة | الاستخدام | الحد الأدنى |
|---|---|---|
| **العلامة المفردة** (Mark) | أيقونة التطبيق، الشريط العلوي المضغوط، favicon | 20×20 px |
| **الأفقي كامل** (Lockup) | الشريط العلوي، رأس التقارير، الصفحات العامة | 132×32 px |
| **الأفقي مختصر** | الشاشات الضيقة | 96×24 px |
| **الرأسي** | شاشات البداية، الطباعة الرسمية | 96×120 px |
| **أحادي اللون** | الطباعة، الختم، التطريز، الفاكس | 16×16 px |

### القفل الأفقي

```
┌──────┐   الحي الدبلوماسي الذكي          ← 15px · وزن 700
│ ▲    │   DQ Smart District              ← 9px  · وزن 500 · تتبّع 0.08em
└──────┘
  32px      ↑ فاصل 10px ↑
```

قاعدة التناسب: ارتفاع النص العلوي = 47% من ارتفاع العلامة. الفاصل = 31% من ارتفاع العلامة.

## 4. ألوان الشعار

| السياق | الدرع | المثلث | القاعدة |
|---|---|---|---|
| على فاتح | `--brand-700` `#0E2A47` | `--accent-500` `#C8A02E` | الافتراضي |
| على داكن | `--accent-500` `#C8A02E` | `--brand-050` `#EAF1F9` | العكس |
| أحادي غامق | `#0E2A47` | شفاف (محفور) | طباعة |
| أحادي فاتح | `#FFFFFF` | شفاف (محفور) | على صورة |
| متدرج (رسمي فقط) | `#0E2A47 → #1B3E63` | `#C8A02E → #E0BE55` | أغلفة العروض |

## 5. قواعد الاستخدام

### ✅ افعل
- استخدم SVG دائمًا — الشعار متجهي
- احترم الهامش الآمن (12.5% من العرض) في كل الاتجاهات
- استخدم النسخة العكسية على الخلفيات الداكنة
- على الصور: ضع طبقة تعتيم `rgba(14,42,71,0.55)` قبل الشعار

### ❌ لا تفعل
| المخالفة | لماذا |
|---|---|
| تدوير الشعار بأي زاوية | البوابة عمودية بطبيعتها |
| تغيير نسب العلامة | الشبكة الهندسية تنهار |
| إضافة ظل أو حد أو توهج | العلامة مسطّحة بقرار |
| وضع نص داخل الهامش الآمن | يفقد الشعار تنفّسه |
| استخدام العلامة كخلفية أو نقش | ليست عنصرًا زخرفيًا |
| تلوين المثلث بغير ألوان النظام | المثلث هو نقطة اللون الوحيدة |
| كتابة `DQ` بدل العلامة | هذا ما نستبدله |

## 7. صوت العلامة

| البُعد | الموضع | يعني |
|---|---|---|
| رسمي ←→ ودود | **رسمي مهني** — 30% نحو الودّ | «تم اعتماد التصريح» لا «تمام! تصريحك جاهز 🎉» |
| موجز ←→ مفصّل | **موجز** — 20% نحو التفصيل | العنوان يكفي؛ التفصيل عند الطلب |
| حازم ←→ لطيف | **حازم عند الرفض، لطيف عند الخطأ** | «الدخول مرفوض» صريحة · «تحقق من التاريخ» لا «خطأ في الإدخال» |
| تقني ←→ إنساني | **إنساني** | «الإيقاف حتى 17 أغسطس» لا `suspension.untilISO` |

**قاعدة حاكمة:** الرسالة تقول **ما حدث** و**ما الخطوة التالية**. لا تعتذر، ولا تلوم المستخدم، ولا تخفي السبب.

| ❌ | ✅ |
|---|---|
| «حدث خطأ» | «التصريح خارج فترة الصلاحية — انتهى أمس 14:00» |
| «غير مصرح» | «إيقاف المركبة حتى 17 أغسطس — قرار المشرف سلطان الحمدان» |
| «عملية غير صالحة» | «المحضر معتمد ومقفل — التصحيح يكون بمحضر جديد» |
| «القائمة فارغة» | «لا مخالفات مفتوحة — كل شيء مغلق» |

## 8. التنفيذ

الشعار منفَّذ كمكوّن React متجهي في [`src/components/Logo.tsx`](../../src/components/Logo.tsx):

```tsx
<Logo variant="mark" size={32} />                    // العلامة فقط
<Logo variant="lockup" tone="onDark" />              // الأفقي على داكن
<Logo variant="lockup" compact />                    // الأفقي المختصر
```

لا صور نقطية. لا ملفات خارجية. مكوّن واحد يولّد كل النسخ من نفس المسارات الهندسية.
