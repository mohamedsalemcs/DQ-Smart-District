# المصطلحات — Glossary

`BA` · v1.0
كل مصطلح: العربية، الإنجليزية، المعرّف في الكود، والمعنى الدقيق.

---

## كيانات الأعمال

| العربية | English | الكود | المعنى |
|---|---|---|---|
| عقار / وحدة | Property / Unit | `Property` | وحدة عقارية مسجلة: فيلا · شقة · تجاري · سفارة · مرفق |
| مقيم | Resident | `Person` role `resident` | فرد مرتبط بوحدة، يقرأ ويبلّغ ولا يفوّض |
| مالك | Owner | `Person` role `owner` | صاحب الوحدة — أعلى صلاحية على ملفها |
| مستأجر | Tenant | `Person` role `tenant` | شاغل الوحدة بعقد |
| مفوّض | Delegate | ✨ غير مبني | من يُنشئ تصاريح نيابة عن المالك |
| مركبة | Vehicle | `Vehicle` | سيارة مسجلة بلوحة وحالة وصول |
| **حالة الوصول** | **Access State** | `accessState` | **الحقيقة الوحيدة لأهلية الدخول:** `allowed` · `suspended` · `blocked` |
| إيقاف | Suspension | `Suspension` | تعليق مؤقت **بمدة محددة** لحق دخول مركبة، بقرار مشرف |
| حظر | Block | `blocked` | منع **دائم** لا ينتهي بالزمن — قرار إداري فقط |
| تصريح | Permit | `Permit` | إذن دخول مؤقت لشخص أو مركبة، بنافذة زمنية وبوابات محددة |
| بلاغ / طلب خدمي | Service Request | `ServiceRequest` | ملاحظة يرفعها مقيم أو مستشعر عن خدمة أو مرفق |
| مخالفة | Violation | `Violation` | واقعة مخالفة موثّقة على مركبة أو عقار أو شخص |
| **سلّم التصعيد** | **Escalation Ladder** | `EscalationSettings.ladder` | تسلسل العقوبات الإدارية — **بيانات قابلة للتعديل لا كود** |
| درجة التصعيد | Escalation Step | `escalationStep` | موضع المخالفة على السلّم (0–5) |
| مهلة تصحيح | Grace Period | `graceUntilISO` | مدة تُمنح للمخالف لتصحيح وضعه قبل التصعيد |
| التكرار | Repeat Count | `repeatCount` | عدد سوابق نفس الموضوع **خلال 12 شهرًا** + الحالية |
| تظلّم | Appeal | `Appeal` ✨ | اعتراض المخالَف على المخالفة — **يوقف عدّاد المهلة** |
| بلاغ أمني | Incident | `Incident` | واقعة أمنية بحاجة استجابة، لها رقم معاملة |
| **رقم المعاملة** | **Transaction No.** | `txnNo` | `DQ-YYYY-NNNNNN` — يصدر لحظة الإنشاء ولا يتغير أبدًا |
| **محضر** | **Maḥḍar / Official Record** | `Mahdar` | وثيقة الواقعة الرسمية: وقائع · تسوية · مضبوطات · تنازل · توقيعات |
| تنازل | Waiver | `waiver` | إقرار الأطراف بالتنازل عن المطالبات المتبادلة |
| مضبوطات | Seized Items | `SeizedItem` | ما ضُبط في الواقعة، بسلسلة عهدة |
| سلسلة العهدة | Chain of Custody | `custody` | تسلسل من تعامل مع المضبوط: ضُبط · رُقّم · خُزّن · حُقّق · سُلّم |
| **القفل** | **Lock** | `locked` | حالة نهائية للمحضر — كل تعديل بعدها مرفوض ومسجَّل |
| **سلسلة التحقق** | **Hash Chain** | `hashChain` | `sha256(البصمة السابقة + الحمولة)` — أي تلاعب يكسرها |
| **سجل التدقيق** | **Audit Trail** | `AuditEntry` | سجل **ملحَق فقط** لكل طفرة، بالفاعل والوقت والقيمة قبل/بعد |
| وردية | Shift | `Shift` | فترة عمل الحارس: حضور · عهدة · تسليم |
| دورية | Patrol | `Patrol` | وحدة متنقلة تُسنَد للبلاغات |
| جولة تفتيش | Tour | `Checkpoint` + `CheckpointScan` | مرور موثّق على نقاط محددة بمسح رمزها |
| نقطة تفتيش | Checkpoint | `Checkpoint` | موقع بجهاز رمز يُمسح لإثبات المرور |
| زمن الاستجابة | Response Time | `responseSeconds` | تأكيد الوصول − وقت الإسناد · **محسوب آليًا** |
| بوابة | Gate | `Gate` | نقطة دخول مادية |
| **حدث بوابي** | **Gate Event** | `GateEvent` | تسجيل كل مسح **أيًا كانت نتيجته** — السجل هو الإثبات |
| قرار البوابة | Gate Decision | `GateDecision` | `allowed` · `denied` · `escalated` |
| تجاوز يدوي | Manual Override | `method: 'manual'` ✨ | فتح استثنائي بقرار مشرف وسبب موثّق |
| موعد سفارة | Embassy Appointment | `EmbassyAppointment` | حجز زيارة عبر الرابط العام للسفارة |
| الحد اليومي | Daily Limit | `embassyConfigs.dailyLimit` | أقصى مواعيد لسفارة في اليوم |
| تصريح زائر مدفوع | Visitor Pass | `VisitorPass` | تصريح يومي بـ50 ريالًا + طلبات مطاعم مسبقة |
| حجز مرفق | Booking | `Booking` | حجز ملعب أو حديقة — رمزه يُقبل عند البوابة |
| أصل | Asset | `Asset` | عنصر بنية تحتية: حاوية · عمود إنارة · خزان ري · مضخة · شجرة |
| أمر عمل آلي | Auto Work Order | — | بلاغ يُنشئه المستشعر عند تجاوز حد (80% امتلاء) |
| اتفاقية مستوى الخدمة | SLA | `dueISO` · `slaBreached` | مهلة الإنجاز المتوقعة ومؤشر تجاوزها |
| التوأم الرقمي | Digital Twin | `DQTwin` | نموذج 3D جغرافي حي للحي بكل طبقاته |

## مصطلحات تقنية

| المصطلح | المعنى في هذا المشروع |
|---|---|
| **الشخصية** (Persona) | البوابة التي تدخل منها: `resident` · `admin` · `security`. تحدد ما **تراه** |
| **الدور** (Role) | صفتك الوظيفية: `supervisor` · `guard` · `admin_staff`… تحدد ما **تفعله** |
| **الصلاحية** (Permission) | إجراء ذرّي: `violation.suspend_vehicle`. نقطة الفحص الفعلية |
| **الشريحة** (Slice) | وحدة من المخزن تخص دومينًا واحدًا، بنمط موحّد: حراسة ← طفرة ← تدقيق ← إشعار ← توست |
| **آلة الحالة** (State Machine) | خريطة الانتقالات المسموحة؛ غير المسموح **يرمي** |
| **الفاعل** (Actor) | المستخدم الحقيقي الذي نفّذ الإجراء — لا دور مفترض |
| **الرابط العميق** (Deep Link) | مسار يفتح **الكيان المعني تحديدًا** لا الصفحة الأم |
| **العزل الاتجاهي** (Bidi Isolation) | `<bdi>` يمنع انقلاب المقاطع اللاتينية داخل النص العربي |
| **الرمز التصميمي** (Design Token) | قيمة بصرية مسمّاة — لا قيمة خام في أي مكوّن |
| **التخطيط المنطقي** (Logical Layout) | `start`/`end` بدل `left`/`right` — ينعكس تلقائيًا في RTL |

## اصطلاحات التسمية في الكود

| اللاحقة/البادئة | المعنى | مثال |
|---|---|---|
| `…Ar` | نص عربي معروض للمستخدم | `labelAr` · `reasonAr` |
| `…Id` | معرّف كيان | `propertyId` · `patrolId` |
| `…ISO` | تاريخ ووقت ISO-8601 UTC | `validFromISO` · `untilISO` |
| `is…` / `has…` / `can…` | قيمة منطقية | `isPast` · `canSuspend` |
| `…Kind` | نوع ضمن اتحاد نصي | `PermitKind` · `IncidentKind` |
| `…Status` | حالة ضمن آلة حالة | `PermitStatus` · `ViolationStatus` |

## أنماط التعبير في الواجهة

| النمط | القاعدة | مثال |
|---|---|---|
| الحالة | **لون + أيقونة + كلمة** — الثلاثة دائمًا | 🔴 ⚠️ «مصعّدة» |
| الرفض | **السبب + المدة + من قرر + المصدر + الخطوة التالية** | «الدخول مرفوض — مخالفة متكررة · حتى 17 أغسطس · قرار سلطان الحمدان · المخالفة TR-07» |
| الخطأ | **ما حدث + ما العمل** — لا اعتذار ولا لوم | «التصريح خارج فترة الصلاحية — انتهى أمس 14:00» |
| الفراغ | **لماذا فارغ + الخطوة التالية** | «لا مخالفات مفتوحة — كل السجلات مغلقة» |
| التأكيد | **الأثر لا السؤال** | «سيصبح السجل نهائيًا — أي تعديل لاحق سيُرفض ويُسجَّل» |
