# الوصولية وRTL — Accessibility & RTL

`Senior UX Designer` · v1.0
**المعيار المستهدف: WCAG 2.1 المستوى AA، والمستوى AAA للمسارات الحرجة للسلامة.**

---

## 1. لماذا هذا ملزم لا اختياري

1. **إلزام تنظيمي** — منظومة تخدم جهة حكومية وسفارات تخضع لمعايير وصولية
2. **إلزام تشغيلي** — الحارس يعمل تحت شمس الرياض وفي الظلام؛ التباين المنخفض يفشل قبل أن يفشل مع ذوي الإعاقة
3. **إلزام سلامة** — قرار البوابة يجب أن يُقرأ صحيحًا في كل الظروف
4. **~8% من الذكور** لديهم خلل في تمييز الألوان — والحراس في الغالب ذكور

### 3.2 لوحة المفاتيح

| المتطلب | التنفيذ |
|---|---|
| كل عنصر تفاعلي يُوصل | `<button>`/`<a>` — لا `<div onClick>` |
| ترتيب منطقي | يتبع ترتيب DOM |
| حبس التركيز في الحوارات | حبس + `Escape` يغلق |
| **إعادة التركيز** | يُحفظ المُفعِّل ويُعاد إليه عند الإغلاق |
| رابط تخطٍّ | «تخطي إلى المحتوى» أول عنصر |
| اختصارات | `/` بحث · `Escape` إغلاق · `g` ثم `g` للبوابة |

### 3.3 قارئ الشاشة

| العنصر | المتطلب |
|---|---|
| **لوحة قرار البوابة** | `role="status"` + **`aria-live="assertive"`** — القرار يُعلَن فورًا |
| التوست | `role="status"` + `aria-live="polite"` |
| شارة الإشعارات | `aria-label="الإشعارات — 3 غير مقروءة"` |
| حالات التحميل | `aria-busy="true"` |
| أخطاء النماذج | `aria-invalid` + `aria-describedby` + `role="alert"` |
| الأيقونات الزخرفية | `aria-hidden="true"` |
| الأيقونات الدالة | `aria-label` عربي |
| الرسوم البيانية | `<figcaption>` + جدول مكافئ |
| سلّم التصعيد | `<ol>` + `aria-current="step"` |

## 4. RTL — العربية أصلية لا مترجمة

### 4.1 القاعدة المطلقة

> **لا خاصية فيزيائية (`left`/`right`) في أي مكوّن. أبدًا.**

| ❌ | ✅ |
|---|---|
| `ml-2` `pr-4` | `ms-2` `pe-4` |
| `text-left` | `text-start` |
| `border-l` | `border-s` |
| `left-0` | `start-0` |
| `rounded-tl` | `rounded-ss` |

**الكود الحالي ملتزم بالكامل.** نقطة قوة حقيقية — الغالبية العظمى من المنتجات العربية تُبنى LTR ثم تُقلب، فتتكسّر. هذا بُني RTL أصلًا.

### 4.2 العزل الاتجاهي — `BR-006`

كل مقطع لاتيني داخل نص عربي **يُعزَل بـ`<bdi>`**:

```tsx
<span>اللوحة <bdi className="plate">ن د ب 4821</bdi> مرفوضة</span>
```

بلا العزل تظهر `1284` بدل `4821` — **خطأ مطابقة كارثي عند البوابة.**

**المطبَّق على:** اللوحات · أرقام المعاملات · رموز QR · بصمات sha-256 · أرقام الجوال والهوية · رموز الوحدات · الأوقات `HH:mm`.

### 4.3 الاتجاه في العناصر البصرية

| العنصر | الاتجاه | لماذا |
|---|---|---|
| سلّم التصعيد | **الدرجة 0 أقصى اليمين** | التقدّم يتبع اتجاه القراءة |
| الخط الزمني | الأحدث أعلى، الحدث يمينًا | |
| محور الزمن في الرسوم | **يمين ← يسار** | الأحدث في اتجاه بداية القراءة |
| الأعمدة الأفقية | تنمو من اليمين | |
| نجوم التقييم | **`dir="ltr"`** | تُقرأ يسار←يمين عالميًا |
| مؤشرات التقدم | تمتلئ من اليمين | |
| أيقونات الاتجاه (رجوع/تالٍ) | **تنعكس** | «رجوع» يشير يمينًا في RTL |

### 4.4 الأرقام والتواريخ

| البند | القرار | لماذا |
|---|---|---|
| نظام الأرقام | **غربي** (0123456789) | لوحات المركبات السعودية وأرقام المعاملات تُطبع غربية؛ اختلاف النظام بين الشاشة والواقع يخلق خطأ مطابقة (`ADR-005`) |
| التقويم | **ميلادي** بأسماء شهور عربية | «14 يوليو 2026» |
| الوقت | **24 ساعة** `HH:mm` | لا التباس صباح/مساء في السجل الأمني |
| الأرقام الجدولية | **`tnum` إلزامي** | بدونها لا تصطف الأعمدة |
| النسبي | «قبل 3 دقائق» عربي | |

## 5. التصميم الشامل — ما وراء الامتثال

| البُعد | المعالجة |
|---|---|
| **الشمس المباشرة** | تباين AAA على البوابة · لا نص رمادي فاتح |
| **اليد الواحدة** | إجراءات المقيم في النصف السفلي · زر الطوارئ في متناول الإبهام |
| **القفازات** | مساحات لمس 56px على شاشة البوابة |
| **الضجيج** | لا اعتماد على الصوت إطلاقًا |
| **الإجهاد** (وردية 12 ساعة) | سطح داكن ليلًا · لا وميض · تسلسل بصري واضح |
| **دوران وظيفي عالٍ** | لا اختصارات مخفية · كل إجراء موسوم نصًا |
| **اتصال ضعيف** | حالات تحميل واضحة · لا فشل صامت |
| **جهاز متواضع** | لا حركة مكلفة على البوابة · تحميل كسول للـ3D |

## 6. قائمة فحص الوصولية لكل مكوّن جديد

- [ ] كل نص ≥ 4.5:1 · الكبير ≥ 3:1 · **المسارات الحرجة ≥ 7:1**
- [ ] كل مكوّن غير نصي ≥ 3:1
- [ ] لا نص تحت 12px · الحد المقروء 13px
- [ ] كل حالة = لون + أيقونة + كلمة
- [ ] يعمل كليًا بلوحة المفاتيح
- [ ] حلقة تركيز مرئية بتباين ≥ 3:1
- [ ] كل عنصر تفاعلي `<button>`/`<a>`
- [ ] الحوارات: حبس تركيز + إعادته + `Escape`
- [ ] الأيقونات الزخرفية `aria-hidden`
- [ ] الأيقونات الدالة `aria-label` عربي
- [ ] النتائج الحاسمة `aria-live`
- [ ] أخطاء النماذج مرتبطة بحقولها
- [ ] مساحات اللمس ≥ 44px (56px على البوابة)
- [ ] لا خاصية فيزيائية للاتجاه
- [ ] كل مقطع لاتيني معزول بـ`<bdi>`
- [ ] الحركة تحترم `prefers-reduced-motion` (حركات **وتكرار**)
- [ ] الحالات الأربع مُعالَجة: تحميل · فراغ · خطأ · جزئي
