## DEF-001 · الإيقاف لا ينتهي أبدًا

| | |
|---|---|
| **الموديول** | `MOD-04` المخالفات · `MOD-05` البوابة |
| **الملف** | [`src/lib/rules.ts:104`](../../src/lib/rules.ts#L104) · [`src/store/slices/violations.ts:103`](../../src/store/slices/violations.ts#L103) |
| **الشدة** | 🔴 P0 — **يمنع الإنتاج** |

**الوصف**
`suspendVehicleFromViolation` يكتب `suspension.untilISO = daysFromNow(days)`، وكل الواجهات تعرضه بثقة: «الإيقاف حتى 17 أغسطس»، «فترة الإيقاف: 3 أغسطس ← 17 أغسطس». لكن `evaluateGate()` يفحص:

```ts
if (vehicle.accessState === 'suspended' && vehicle.suspension) {
  return { decision: 'denied', … };   // ← لا ينظر إلى untilISO إطلاقًا
}
```

**لا يوجد في المنتج كله** مؤقّت أو فحص أو مهمة تعيد `accessState` إلى `allowed` بعد انقضاء المدة.

**خطوات إعادة الإنتاج**
1. الأمن ← تسجيل مخالفة على `ن د ب 4821`
2. الإدارة ← المخالفات ← إشعار ← تصعيد ×2 ← إيقاف المركبة لمدة **1 يوم**
3. غيّر ساعة الجهاز ليومين للأمام (أو اضبط المدة إلى 0)
4. الأمن ← البوابة ← امسح `ن د ب 4821`

**المتوقع:** مسموح — انتهت مدة الإيقاف
**الفعلي:** **الدخول مرفوض** — إلى الأبد

**الأثر التجاري**
النظام يفرض عقوبة **أشد مما قرره المشرف**. إيقاف 14 يومًا = حرمان دائم من دخول المسكن. أثر قانوني مباشر، وانهيار كامل لثقة المستخدم بأي وعد آخر يقطعه النظام.

**الإصلاح** `BR-121` · `SM-05`
دالة `reconcileSuspensions()` تُستدعى من موضعين:
1. **عند القراءة** في `evaluateGate()` — يمنع أي رفض خاطئ حتى لو تجمّد المؤقّت
2. **كل نبضة مستشعر** (3 ثوانٍ) — يصحّح الحالة في المخزن ويُشعر ويسجّل في التدقيق

الفحص عند القراءة **وحده كافٍ للصحة**؛ النبضة تضيف التصحيح المرئي والإشعار.

## DEF-002 · «البوابات المسموحة» حقل ميت

| | |
|---|---|
| **الموديول** | `MOD-02` التصاريح · `MOD-05` البوابة |
| **الملف** | [`src/lib/rules.ts:132`](../../src/lib/rules.ts#L132) · [`src/personas/resident/PermitNew.tsx:32`](../../src/personas/resident/PermitNew.tsx#L32) |
| **الشدة** | 🔴 P0 |

**الوصف**
المقيم **مجبر** على اختيار بوابة واحدة على الأقل:
```ts
if (gateIds.length === 0) errs.push('اختر بوابة واحدة على الأقل');
```
القيمة تُخزَّن في `permit.gateIds`، والنوع يعرّفها، والبذرة تملؤها — و`evaluateGate()` **لا يذكرها في أي سطر**. بحث نصي عن `gateIds` في كامل المصدر يعطي 8 مواضع، **ولا واحد منها في منطق قرار البوابة**.

**إعادة الإنتاج**
1. المقيم ← تصريح جديد ← اختر **البوابة الجنوبية فقط**
2. الإدارة ← اعتماد
3. الأمن ← **البوابة الرئيسية** ← امسح رمز التصريح

**المتوقع:** مرفوض — التصريح لا يشمل هذه البوابة
**الفعلي:** **مسموح بالدخول**

**الأثر:** ضابط أمني كامل مُعطَّل بصمت. المستخدم يظن أنه قيّد الوصول ولم يقيّد شيئًا — وهذا **أسوأ من عدم وجود الميزة**.

**الإصلاح** `BR-033` — `evaluateGate` صار يستقبل `gateId` ويرفض عند بوابة غير مدرجة بسبب صريح يسمّي البوابات المسموحة.

## DEF-003 · الطريق المسدود في المحضر

| | |
|---|---|
| **الموديول** | `MOD-06` · `MOD-07` |
| **الملف** | [`src/personas/security/Mahdar.tsx:899`](../../src/personas/security/Mahdar.tsx#L899) · [`src/personas/security/IncidentNew.tsx:52`](../../src/personas/security/IncidentNew.tsx#L52) |
| **الشدة** | 🔴 P0 |

**الوصف**
`IncidentNew` يسجّل الأطراف من حقل «اسم السائق» **فقط**:
```ts
parties: driverName.trim() ? [{ nameAr: driverName, role: 'subject' }] : [],
```
و`Mahdar` يشترط للاعتماد:
```ts
const allSigned = incident.parties.length > 0 && incident.parties.every(p => p.signatureDataUrl);
```
بلاغ بلا اسم سائق ⇒ `parties = []` ⇒ `allSigned = false` **دائمًا** ⇒ زر «اعتماد وقفل المحضر» `disabled` **للأبد** ⇒ البلاغ عالق في `pending_mahdar` ولا يُغلق.

**وهذا هو المسار الافتراضي** لأنواع البلاغات: تجمهر، جسم مشتبه به، عطل جهاز، مفقودات، حريق — لا أطراف لها أصلًا.

**إعادة الإنتاج**
1. الأمن ← البلاغات ← بلاغ جديد ← نوع «تجمهر» ← املأ الإلزامي ← **اترك اسم السائق فارغًا**
2. إسناد دورية ← تأكيد الوصول ← فتح المحضر
3. املأ الملخص والتسوية
4. انظر لزر «اعتماد وقفل المحضر»

**المتوقع:** قابل للضغط
**الفعلي:** معطّل بنص «بانتظار توقيع جميع الأطراف» — **وليس هناك أطراف لتوقّع**

**الأثر:** مسار كامل (Path B) ينهار لكل الأنواع عدا المشاجرة والحادث المروري. البلاغات تتراكم في حالة معلّقة بلا مخرج.

**الإصلاح** `BR-084` — الشرط صار `parties.every(signed)`؛ المصفوفة الفارغة تُرجع `true` منطقيًا، والمشرف يعتمد بإقراره وحده. النص التوضيحي يميّز الحالتين.

**الوصف**
