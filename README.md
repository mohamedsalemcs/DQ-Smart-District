# الحي الدبلوماسي الذكي — DQ Smart District

منظومة تشغيل حي مغلق: **ثلاث منصات مستقلة** على حالة مشتركة واحدة.
القرار الإداري يصبح إنفاذًا آليًا عند البوابة، وكل خطوة في سجل لا يُعدَّل.

---

## البنية

```
apps/
├── landing/     :5170  /            صفحة اختيار المنصة
├── admin/       :5171  /dashboard/  مركز القيادة — ثنائي اللغة (عربي افتراضيًا)
├── security/    :5172  /ops/        التشغيل الأمني
└── resident/    :5173  /portal/     بوابة المقيم

packages/
├── core/    منطق الأعمال — الأنواع · آلات الحالة · قرار البوابة · المخزن
└── ui/      نظام التصميم — الرموز · الخطوط · الشعار · المكونات

_SOURCE/     مصدر المراجع: 33 مستندًا من ست وجهات نظر مهنية
```

**لماذا ثلاث منصات لا تطبيق بثلاث شخصيات:** كل منصة لها جمهور وجهاز وكثافة مختلفة — الحارس على لوحي بيد واحدة، والموظفة على شاشة مكتبية كثيفة، والمقيم على هاتف. الفصل يجعل كل حزمة أخف ويسمح بنشر مستقل. المنطق يبقى واحدًا في `packages/core`.

## التشغيل

```bash
npm install
npm run dev          # المنصات الأربع معًا
```

| المنصة | الرابط |
|---|---|
| اختيار المنصة | http://localhost:5170 |
| مركز القيادة | http://localhost:5171/dashboard/ |
| التشغيل الأمني | http://localhost:5172/ops/ |
| بوابة المقيم | http://localhost:5173/portal/ |

منصة واحدة فقط:

```bash
npm run dev:admin      # أو dev:security · dev:resident · dev:landing
```

البناء والنشر:

```bash
npm run build          # يبني الأربع ويجمعها في dist/
npm run preview        # معاينة نسخة الإنتاج
npm run typecheck      # فحص الأنواع للمستودع كله
```

**Vercel:** نشرة واحدة تخدم الأربع — `vercel.json` جاهز، والمخرج `dist/`.

## نظام التصميم

### الهوية
هوية جديدة كليًا: **تيل عميق** (`#0e6a60`) — مدني · مستدام · مؤسسي. ثيم فاتح في المنصات الثلاث.
الشعار **بوابة ودرع** متجهي (`packages/ui/src/Logo.tsx`) — القوس بوابة، والدرع حماية، والفتحة السفلية تقول إن الحي مدخل لا حصن.

### التباين
كل نسبة محسوبة بمعادلة WCAG 2.1، لا مقدَّرة:

| العنصر | النسبة |
|---|---|
| النص الأساسي | 14.77 · AAA |
| النص الثانوي | 5.44 · AA |
| نص العلامة | 8.67 · AAA |
| **لوحة «مسموح» عند البوابة** | **7.55 · AAA** |
| **لوحة «يتطلب تحقق»** | **7.69 · AAA** |
| **لوحة «مرفوض»** | **9.42 · AAA** |
| حلقة التركيز | 6.46 |

**صفر إخفاق تباين.** اللوحة السابقة كان فيها سبعة، أخطرها لوحة «يتطلب تحقق» عند **3.26** — على الشاشة الوحيدة الموصوفة بأنها «تُقرأ من ثلاثة أمتار».

### الخطوط — محزَّمة محليًا، صفر طلبات شبكة
عائلة واحدة `DQ Sans` بعدة `@font-face` لكل منها `unicode-range`:

- **Cairo** → الحروف العربية فقط
- **Inter** → الأرقام والحروف اللاتينية وعلامات الترقيم

المتصفح يختار الخط لكل محرف، فتظهر «اللوحة ن د ب 4821» بخطين في كلمة واحدة بلا أي تغليف يدوي.
الملفات من `@fontsource` تُحزَم في البناء — لا اتصال بـGoogle Fonts.

## ما أُصلح

تدقيق كامل لـ11,278 سطرًا أخرج **47 عيبًا**، منها **9 حرجة**. أبرزها:

| # | كان | صار |
|---|---|---|
| `DEF-001` | **الإيقاف لا ينتهي أبدًا** — `untilISO` يُكتب ويُعرض ولا يُفحص. إيقاف 14 يومًا = إيقاف أبدي | ينتهي تلقائيًا · فحص عند القراءة + نبضة دورية |
| `DEF-002` | **«البوابات المسموحة» حقل ميت** — المقيم مجبر على اختيارها ولا تُقرأ في القرار | البوابة تحترمها وترفض بسبب يسمّي المسموح |
| `DEF-003` | **طريق مسدود** — بلاغ بلا أطراف ⇒ زر الاعتماد معطّل للأبد | المصفوفة الفارغة تستوفي الشرط · المشرف يعتمد بإقراره |
| `DEF-004` | **إشعارات تذهب للعدم** — الموجّه لشخص لا يظهر لأحد | يصل لصاحبه |
| `DEF-005` | **رمز العقار يفتح البوابة** — وهو مطبوع على لوحة الوحدة | بطاقة تعريف · القرار للحارس |
| `DEF-006` | **تزوير المُقرِّر** — القرار يُنسب لأول مشرف في المصفوفة | الفاعل الحقيقي |
| `DEF-023` | حجزان على نفس الملعب نفس الساعة | كشف تعارض |
| `DEF-024` | حد السفارات يُخترق — الحضور يحرّر مقعدًا | يشمل الحاضرين |

**وأُضيف:** التظلّمات (`EP-20`) · التجاوز اليدوي بقرار مشرف · اتجاه المسح · SLA نافذ · إغلاق بلا محضر.
